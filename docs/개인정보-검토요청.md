# 개인정보 동의·처리방침 — 대표님 확인 요청

초안은 홈페이지에 반영해 두었습니다.
- 신청 폼의 동의 안내: `/diagnosis/` 맨 아래 **[필수] 개인정보 수집·이용 동의 → 내용 보기**
- 처리방침 전문: `/privacy/`

문구는 `src/data/privacy.ts` 한 곳에서 고치면 두 화면이 같이 바뀝니다.
아래 표의 **기본값**이 마음에 들면 그대로, 바꿀 부분만 알려주세요.

| # | 확인할 것 | 지금 기본값 | 메모 |
|---|---|---|---|
| 1 | 필수로 받을 항목 | 상호명, 업종, 연락처 | 최소한으로 둠. 이름은 받지 않음 |
| 2 | 선택 항목 | 도움 유형, 지역, 운영 채널 주소, 고민 내용 | |
| 3 | 이용 목적 | 상담 신청 확인, 연락, 우리 가게에 맞는 운영 제안 | |
| 4 | 보관 기간 | **상담 신청일로부터 1년**, 요청 시 즉시 삭제 | 시트에서 매일 자동 삭제되게 설정함 |
| 5 | 소식·이벤트 안내 | **사용 안 함** (선택 동의 칸 숨김) | 보낼 계획이면 켜기. 상담 동의와 따로 받아야 함 |
| 6 | 처리 위탁·국외 이전 | Google(시트 저장, Gmail 알림), 미국 등 | 구글 서비스를 쓰는 한 적어야 하는 내용 |
| 7 | 보호책임자 | 이준영 대표 / contact@patera.biz | 메일 연결 후 사용 |
| 8 | 방문 분석(GA4) | 연결하면 처리방침에 자동으로 항목이 추가됨 | 연결 여부 결정 필요 |
| 9 | 시행일 | 정식 공개일 | 공개일 정해지면 기입 |

확정되면 `status: 'final'`, `effectiveDate` 를 채우고 "초안" 표시를 뗍니다.

> 이 초안은 개인정보 보호법의 일반 기준(수집 항목·목적·보유 기간·거부권 고지, 처리방침 공개)에 맞춰 작성했습니다.
> 법률 자문은 아니며, 최종 문구 확인은 운영자 몫입니다.
