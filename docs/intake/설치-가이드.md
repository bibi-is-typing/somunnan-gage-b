# 상담 신청 접수 설치 가이드

홈페이지 상담 신청 → **구글 시트 저장 + 알림 메일**을 연결합니다. 비용은 0원, 15분 정도 걸립니다.
반드시 **소유자(파테라) 구글 계정**으로 진행합니다. (예: cor.patera@gmail.com)

---

## 1. 시트와 스크립트 만들기

1. 구글 드라이브 → 새로 만들기 → **구글 스프레드시트**. 이름: `소문난 가게 상담신청`
2. 메뉴 **확장 프로그램 → Apps Script**
3. 편집기의 기본 코드를 모두 지우고 [`apps-script.gs`](apps-script.gs) 내용을 통째로 붙여넣기 → 저장(💾)

## 2. 설정값 넣기 (코드에 적지 않음)

왼쪽 ⚙️ **프로젝트 설정 → 스크립트 속성 → 속성 추가**

| 속성 | 값 | 설명 |
|---|---|---|
| `NOTIFY_EMAIL` | `cor.patera@gmail.com` | 알림 받을 메일. 여러 명이면 쉼표로 |
| `RETENTION_DAYS` | `365` | 보관 기간(일). 처리방침과 같은 숫자로 |

## 3. 처음 한 번 실행

1. 편집기 위쪽 함수 목록에서 **`setup`** 선택 → ▶ 실행
2. 권한 요청 → 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**
   (내 계정에서 내가 만든 스크립트라 정상입니다)
3. 시트에 `상담신청` 탭과 머리줄이 생기고, 매일 새벽 3시 보관 기간 지난 신청 자동 삭제가 예약됩니다

## 4. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
2. 다음 사용자 인증 정보로 실행: **나** / 액세스 권한: **모든 사용자**
3. 배포 → 나오는 **웹 앱 URL** 복사 (`https://script.google.com/macros/s/…/exec`)
4. 브라우저 새 탭에 그 주소를 열어 `{"ok":true,"service":"somunnan-intake"}` 가 보이면 성공

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**. 주소는 그대로 유지됩니다.
> "새 배포"를 또 누르면 주소가 바뀌니 주의.

## 5. 홈페이지에 주소 넣기

웹 앱 URL을 환경 변수 `PUBLIC_INTAKE_ENDPOINT` 에 넣고 다시 배포합니다.

| 배포 위치 | 넣는 곳 |
|---|---|
| Cloudflare Pages (정식) | 프로젝트 → 설정 → 변수 및 비밀 → `PUBLIC_INTAKE_ENDPOINT` → 다시 배포 |
| GitHub Pages (미리보기) | 저장소 Settings → Secrets and variables → Actions → **Variables** → `PUBLIC_INTAKE_ENDPOINT` |
| 내 컴퓨터 | `.env` 파일에 `PUBLIC_INTAKE_ENDPOINT=주소` |

주소가 비어 있으면 폼은 지금처럼 **미리보기**(전송·저장 안 함)로 동작합니다.

## 6. 확인 (오픈 전 꼭)

| # | 해볼 것 | 기대 결과 |
|---|---|---|
| 1 | 테스트 신청 1건 | 완료 화면 "상담 신청이 접수됐어요", 시트에 한 줄, 알림 메일 1통 |
| 2 | 같은 번호로 바로 1건 더 | 시트에 '중복'으로 한 줄, 메일은 안 옴 |
| 3 | 동의 체크 없이 신청 | 화면에서 막힘, 시트에 안 쌓임 |
| 4 | 휴대폰으로 신청 1건 | 1번과 같음 |
| 5 | 테스트 줄 삭제 | 시트 정리 |

## 운영하면서

- 알림 메일 → 시트 링크 → **처리 상태**를 `새 신청 → 연락 완료 → 계약 / 보류` 로 바꿔 관리
- 시트 **공유는 하지 않기** (필요하면 특정 사람만 보기 권한)
- 구글 계정 **2단계 인증** 켜기 (처리방침에 적혀 있음)
- 일반 구글 계정은 하루 보낼 수 있는 메일 수에 한도가 있어요(약 100통). 넘으면 메일만 안 가고 시트에는 계속 저장됩니다
- 동의 문구를 바꾸면 `src/data/privacy.ts` 의 `consentVersion` 도 바꾸기 (시트에 어떤 문구에 동의했는지 남음)
